# Student Registration Form with Client & Server-Side Validation

A beginner-friendly Full Stack Web Application built using **Node.js**, **Express.js**, **EJS**, **HTML**, **CSS**, and **JavaScript**.

This project demonstrates how to create a registration form with both client-side and server-side validation while temporarily storing submitted user data in server memory.

---

## Features

- Student Registration Form
- Inline CSS Styling
- Inline JavaScript Validation
- Server-Side Validation using Express.js
- Temporary Data Storage (In-Memory Array)
- Dynamic Pages using EJS
- Beginner-Friendly Project Structure

## Validation Features

### Client-Side Validation

- Prevents empty form submission
- Validates minimum age requirement
- Displays alert messages instantly

### Server-Side Validation

- Checks for missing fields
- Prevents invalid submissions
- Processes validated data securely

---

## Temporary Data Storage

Validated user information is stored temporarily in an in-memory array on the server. The data is reset whenever the server restarts.
